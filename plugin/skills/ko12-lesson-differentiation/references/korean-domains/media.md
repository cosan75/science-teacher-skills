# 매체 — 맞춤형 수업의 세 자리

`korean.md`가 영역을 **매체**(코드 `06`)로 판정했을 때 이어서 읽는다.
R1·R2·R5·R6·R8은 `korean.md`에 있고 영역과 무관하다. 여기에는 영역마다 달라지는
**R3(진입점) · R4(기초 스캐폴드) · R7(심화 확장)** 세 자리만 있다.

## R3 — 수준별 진입점

| 수준 | 진입점 |
|---|---|
| 기초(가 모둠) | 자료 훑기(무엇이 보이나) → 분석 틀 채우기 → 문장 지원이 있는 판단 쓰기 |
| 보통(나 모둠) | 분석 → 비판적 수용(빠진 관점·출처 따지기) |
| 심화(다 모둠) | 수용 → 다른 관점의 자료 제작, 유통 방식까지 따지기 |

세 수준 모두 **생산자·의도를 따진다**. 기초에게 내용 확인만 시키면 매체 영역이 읽기 영역으로 주저앉는다.

## R4 — 기초 수준 스캐폴드 (과제당 1–2개)

- ✓ **분석 틀 네 칸 중 한 칸 채워짐** — '누가 만들었나'를 예로 채워 준다
- ✓ **매체 용어 상자** — 생산자·의도·수용자를 일상어로
- ✓ **텍스트 요소 발췌 인쇄** — 화면에만 있던 헤드라인·문구를 지면에 옮겨 준다
- ✓ **판단 문장 지원** — "이 자료는 ____를 크게 놓았다. 그래서 ____를 말하려는 것 같다."
- ✓ **자료를 두 번 볼 기회** — 영상은 한 번 보고 분석하기 어렵다

**이 영역에서 하면 안 되는 것:**

- ❌ 기초에게 내용 요약만 시키기 — 그것은 매체 분석이 아니다
- ❌ 교사가 의도를 먼저 말해 주기
- ❌ 더 단순한 다른 자료로 갈아 끼우기

## R7 — 심화 확장

- **다른 관점으로 다시 제작** — 같은 사실을 다른 편에서
- **같은 사안 두 자료 비교** — 무엇이 같고 무엇이 다르게 다뤄졌나
- **유통 방식까지 따지기** — 이 자료는 누구에게 어떻게 닿는가
- **제작 선택의 근거 설명** — 내가 왜 이 낱말, 이 배치를 골랐는가

## R6이 이 영역에서 깨지는 자리

**분석의 깊이.** 기초 학습지가 '무슨 내용인가'로만 채워지기 쉽다. 세 학습지 모두에 '왜 그렇게 만들었나' 발문이 있는지 확인한다.
