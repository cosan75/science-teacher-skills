# 문법 — 맞춤형 수업의 세 자리

`korean.md`가 영역을 **문법**(코드 `04`)로 판정했을 때 이어서 읽는다.
R1·R2·R5·R6·R8은 `korean.md`에 있고 영역과 무관하다. 여기에는 영역마다 달라지는
**R3(진입점) · R4(기초 스캐폴드) · R7(심화 확장)** 세 자리만 있다.

## R3 — 수준별 진입점

| 수준 | 진입점 |
|---|---|
| 기초(가 모둠) | 언어 자료 관찰(분류) → 문장 지원으로 규칙 진술 → 새 예에 적용 |
| 보통(나 모둠) | 분류 → 규칙 진술 → 적용과 판별 |
| 심화(다 모둠) | 적용 → 반례 찾기, 규칙의 경계 규정 |

세 수준 모두 **규칙을 스스로 찾는다**. 기초에게 용어와 정의를 먼저 주고 외우게 하면 탐구가 사라지고 그 수준만 연역 수업이 된다.

## R4 — 기초 수준 스캐폴드 (과제당 1–2개)

- ✓ **자료를 정렬해 주기** — 비슷한 것끼리 붙여 배열한다. 자료 수를 줄이는 것이 아니다
- ✓ **비문에 표시** — 안 되는 예에 `*`나 '어색한 말' 표시를 붙여 준다
- ✓ **분류 칸 첫 줄 채워짐** — 한 무리의 예를 보여 준다
- ✓ **규칙 진술 문장 지원** — "____일 때는 ____가 된다. 왜냐하면 ____이기 때문이다."
- ✓ **용어표는 명명 단계 뒤에** — 학습지 배치 순서로 탐구를 지킨다

**이 영역에서 하면 안 되는 것:**

- ❌ 용어와 정의를 먼저 주기 — 순서가 뒤집히면 탐구가 확인이 된다
- ❌ 규칙을 알려 주고 적용만 시키기
- ❌ 자료 수를 줄여 규칙이 안 보이게 만들기 — 오히려 어려워진다

## R7 — 심화 확장

- **반례 만들기** — 규칙이 통하지 않는 예를 스스로 찾기
- **규칙의 경계 규정** — 어디까지가 이 규칙의 자리인가
- **자기 말·주변 언어에서 예 수집** — 실제 언어생활에서 찾아오기
- **규칙의 이유 설명** — 왜 국어가 이렇게 되어 있을까

## R6이 이 영역에서 깨지는 자리

**탐구의 순서.** 기초 학습지에서 용어표가 위로 올라가기 쉽다. 세 학습지 모두 관찰 → 진술 → 명명 순서인지 확인한다.
