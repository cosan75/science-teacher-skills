# 수학 — 차별화 pedagogy (초등)

`ko12-lesson-differentiation`에서 과목이 **초등 수학**(초1–6)일 때 로드된다 (SKILL.md 과목 레지스트리).
중·고 수학은 이 포크에서 아직 준비 중이다(planned).

## 원본 수업 확인

네 시나리오 — 어느 것인지 판단한다:

**시나리오 A — 이 대화 앞부분에 원본 수업이 있다.** 그대로 쓴다. 다시 공유해 달라고 하지 않는다.

**시나리오 B — 교사가 원본 수업 파일을 올린다.** 먼저 읽는다. 확인할 것: 학년, 성취기준(코드와 원문),
앵커 문제, 연습 문제의 구조 사례, 수업 단계. 읽히지 않으면 오류를 분명히 말하고 다시 요청한다.
조용히 지어내지 않는다.

**시나리오 B2 — 교사가 링크로 준다.** 가져와 읽고 B와 똑같이 확인한다. 실패하면 붙여넣기나 파일을
요청한다.

**수업을 가져온 것으로 Step 1이 끝날 뿐, 성취기준 확인을 대신하지 않는다.** Step 2로 계속한다.

**시나리오 C — 원본 수업이 없다.** 진행 전에 묻는다:
> "차별화 도와드릴게요. 염두에 둔 수업이 있으신가요? 붙여넣거나 파일로 주셔도 되고,
> 학년 + 주제 + 성취기준만 알려 주셔도 그걸로 만들 수 있어요."

교사가 교과서 차시를 말하면 위치 감각으로만 쓴다. 교과서 문제를 재현하지 않는다.

## 차별화 규칙

여덟 규칙을 모든 차별화 수학 수업에 적용한다.

### R1 — 산출 구조

**교사용 통합 차별화 수업안 1종 + 순수 학생용 학습지 3종. 수준별 수업안 3종을 만들지 않는다.**

수업안은 수업 단계로 조직한다. 모든 학생이 함께하는 단계(문제 만나기, 풀이 나누기, 정리하기)는 한
번만 쓰고, 학생이 따로 푸는 단계(스스로 해결하기, 연습)는 세 수준을 한 표에 나란히 보인다. 교사
노트와 학생 문제가 섞인 문서를 3벌 만들지 않는다.

### R2 — 성취기준 범위 보존

**모든 수준이 원래 성취기준을 다룬다. 성취기준의 구조 사례는 가장 어려운 사례까지 모든 수준에 남는다.**

가장 어려운 사례(단위분수 비교, 받아내림이 두 번 있는 뺄셈, 나머지의 해석 등)는 기초 수준 학생이
스캐폴드와 함께 **가장 만나야 하는** 사례다 — 빼는 사례가 아니다. 인지적 범위를 줄이는 것은 차별화가
아니다.

**흥미는 기초 수준에서도 보존한다.** 재미있는 생활 맥락은 보통·심화에, 계산 반복은 기초에 주지 않는다.
같은 맥락, 같은 문제 — 지원만 다르다.

### R3 — 선수 학습으로 끌어올리기

**기초 수준 스캐폴드는 이름 붙인 선수 학습에 근거해 학생을 학년 수준 과제로 끌어올린다. "그냥 쉽게"가
아니다.**

- ✓ "기초 수준은 [선수 성취기준]의 [시각 모델]로 [개념]을 먼저 드러내고, 그 표현을 학년 수준 문제에
  적용한다."
- ✗ "기초 수준은 더 작은 수 / 더 적은 단계 / 더 짧은 문제를 쓴다."

**선수 학습 찾기 — 첫 결과에서 멈춘다:**
1. **학습맵 선수 경로** — `get_prerequisites`의 경로에서 이 성취기준 바로 앞의 다른 성취기준. ⚠ 초등
   수학에서 성취기준 사이의 edge는 대부분 `soft`("공식 코드 순서에 따른 후보")다. 경로의 마지막 2–3개
   성취기준 가운데 **이 개념에 실제로 필요한 것**을 고르고 "학습맵 코드 순서 후보"로 표시한다.
2. **같은 영역 이전 학년군** — 경로가 없으면 이전 학년군의 같은 영역 성취기준을 `search_standards`로
   찾아 코드 + 10어절 이내 요지로 쓰고 "추정"을 표시한다.
3. **개념 수준 서술** — 코드를 찾지 못하면 선수 개념을 평이한 말로 쓴다: *"선수 개념: [서술] — 해당
   성취기준 코드를 확인하지 못함."*

수업안의 **선수 학습** 줄은 어느 경로를 탔는지 드러낸다. 비워 두거나 일반론으로 쓰지 않는다.

**수학에서 선수 학습이 협상 불가인 이유.** 수학은 쌓이는 과목이다. 이전 학년의 개념이 없는 학생은
스캐폴드만으로 지금 개념을 이해하지 못한다 — 막히는 지점은 대개 오늘 개념이 아니라 선수 개념의 빈틈이다.

#### 구체물 → 그림 → 식 진입점

| 수준 | 진입점 |
|---|---|
| 기초(가 모둠) | 구체물(수 모형, 분수 막대, 바둑돌) → 그림 |
| 보통(나 모둠) | 그림 → 식 |
| 심화(다 모둠) | 식 → 일반화(규칙, 구조, 다음 성취기준과의 연결) |

### R4 — 기초 수준 스캐폴드

**스캐폴드는 생각을 돕되 답을 드러내지 않는다. 답을 알려 주는 힌트 금지. 낱말로 연산 고르기 금지.**

하지 않는 것:
- ❌ 낱말 전략("'모두'가 나오면 더하기") — 상황의 구조를 보는 성취기준을 무너뜨린다
- ❌ 개념 이해 전의 계산 절차 선행 학습
- ❌ 답칸만 비워 둔 채 다 채운 풀이 틀
- ❌ 원래 과제가 풀이를 쓰는 것인데 선택형으로 바꾸기

쓰는 것:
- ✓ 문장 지원: "나는 ____과 ____을 알아요. 모르는 것은 ____이에요."
- ✓ 개념에 맞는 시각 조직자(아래 표)
- ✓ 구체물·그림 발문으로 식까지 잇기(R3의 진입점)
- ✓ 어휘 상자(답을 고르는 용이 아니라 용어용)
- ✓ 명시적 전이 단계가 있는 단순화: "이 수로 먼저 해 보고, 원래 문제에 적용하세요."

#### 개념 → 주 시각 모델

| 개념 유형 | 주 시각 모델 |
|---|---|
| 부분-전체, 덧셈·뺄셈 관계 | 수 막대(테이프 그림), 가르기·모으기 그림 |
| 곱셈·나눗셈 구조, 넓이 | 배열, 넓이 모델 |
| 분수·소수의 크기와 위치 | 수직선, 분수 막대 |
| 비와 비율, 규칙과 대응 | 표, 비율표 |
| 도형의 성질 | 부분에 이름을 붙인 그림 |
| 자료와 가능성 | 표, 그래프 |

렌더러는 그림을 그리지 못한다 — 수직선은 `number_line`, 표는 `fill_table`, 나머지는 학생이 그리는
빈 공간(`answer_box` `ruled: false`)과 "____을 그려 나타내세요" 발문으로 싣는다.

#### 스캐폴드 밀도 상한

**문제 하나에 삽입 스캐폴드 1–2개까지.**

| 종류 | 상한에 세나? |
|---|:-:|
| 삽입 — 문제마다 인쇄되는 조직자, 문장 지원, 힌트 글 | 센다 |
| 머리 — 학습지 위의 어휘 상자, 문장 지원 | 안 센다 |
| 교사 쪽 — 요청 시 구체물, 개별 지도 발문 | 안 센다 |

주 스캐폴드 하나를 먼저 고른다. 두 번째는 진짜 다른 방식을 더할 때만 넣는다.

### R5 — 필수 교수학습 장치

**모든 차별화 수학 수업에 네 가지가 다 있어야 한다.**

| 요소 | 무엇인가 | 어디에 |
|---|---|---|
| **형성 확인** | 수준별 정리 문항이나 수업 중간 확인 문제. "살펴본다"는 해당 없음 | 수업안 + 학습지 |
| **앵커 활동** | 먼저 끝낸 학생용 성취기준 정합 과제. 시간 때우기 금지. `shared.anchor_activity`에 학생 대면으로 쓰고 학습지 3종 모두에 인쇄 | 수업안 + 학습지 3종 |
| **유연한 편성 문구** | 수준 배정이 이 수업의 증거에 근거하며 형성 확인 뒤 바뀔 수 있다는 진술 | 수업안 머리 |
| **수준별 예상되는 학생 반응** | 틀린 식·답의 형태 + 교사 발문 + 소집단이 필요한 신호 | 수준별 활동 블록 안 콜아웃 |

**각 학습지는 세 수준 공통의 성찰 발문 하나로 끝난다** — 예: *"어떤 방법으로 풀었고, 왜 그 방법을
골랐나요?"* `shared.reflect_prompt`에 저장하고 수업안의 각 수준 **학습지 과제** 줄에 이름을 적는다.

### R6 — 보이지 않는 조정

**수준 간 같은 맥락, 같은 핵심 문제, 같은 구조적 도전. 지원만 다르다.**

달라져도 되는 것: 학습지의 스캐폴드, 교사의 개별 지도, 확장 발문의 깊이.
달라지면 안 되는 것: 문제 맥락, 핵심 질문, 성취기준이 겨누는 구조적 도전.

**스캐폴드가 빠지는 것을 학생에게 알리지 않는다.** 문제 1에 있던 조직자가 문제 3에 없으면 그 부재는
조용하다 — "(이번에는 그림 없이)" 같은 말 금지.

**수는 기본적으로 같다.** 수학적 구조가 온전히 보존될 때만 기초 수준의 수를 바꿀 수 있다 — 핵심 도전을
없애지 않는다(분수를 자연수로 바꾸지 않는다, 받아내림이 있는 문제를 없는 문제로 바꾸지 않는다).

### R7 — 수준 내 점진적 스캐폴딩

**각 학습지는 문제를 인지적 요구가 커지는 순서로 배열한다.**

#### 기초 수준 제거 방식

| 문제 | 삽입 스캐폴드 | 방식 |
|---|:-:|---|
| 문제 1 | 최대 2 | 구조화 |
| 문제 2 | 최대 1 | 안내 |
| 문제 3 이후 | 0 | 스스로 |
| 정리 문항 | 0–1 | 도달 확인 |

#### 심화 수준 확장 품질 검사

모든 심화 확장은 이 질문에 답해야 한다: **보통 수준 학생이 이미 하고 있지 않은 어떤 새 사고를 요구하는가?**

| 종류 | 무엇을 요구하나 |
|---|---|
| 새 인지 작용 | 보통은 적용하고, 심화는 분석·평가·창작한다 |
| 구조 통찰 | 보통이 한 사례로 다루는 것의 일반화, 같음, 역관계 |
| 다음 성취기준 예고 | 다음 학년군 성취기준의 실제 개념 요소 — 표기나 용어만이 아니라 |
| 열린 생성 과제 | 문제 만들기, 반례 설계, 처음부터 논증 세우기 |

거절할 것: 표기만 바꾼 것, 같은 것을 더 많이, 다시 말하기.

### R8 — 범위와 기본값

**수준 범위가 지정되지 않았으면 생성 전에 하나로 묶어 묻는다:**

> "기초 / 보통 / 심화 세 수준으로 나눌게요 — 이 셋이 맞을까요? 그리고 알아 둘 학생 정보가 있을까요
> (한국어 지원이 필요한 학생, 개별화교육 목표 등)? 없으면 보편적 설계 기본값(세 수준 모두 문장 지원과
> 어휘 지원)으로 진행합니다."

**지정되지 않았을 때 조용히 적용하는 기본값:**
- 수준: 기초 / 보통 / 심화 (학생 문서에서는 가 / 나 / 다 모둠)
- 보편적 설계: 문장 지원과 어휘 정리를 **학습지 3종 모두**에(기초에만이 아니라)
- 범위: 수업 전체(정리 문항 포함)

**생성 뒤에 묻는 형성평가 질문:**
> "정리 문항 결과나 진단 점수, 학생들이 막힌 지점에 대한 메모가 있으신가요? 예를 들어 개념은 알았는데
> 계산 절차에서 틀렸는지, 개념 자체가 헷갈렸는지요."

이 질문은 기본 수업안을 **낸 뒤에** 한다. 수학에서는 형성평가 자료가 스캐폴드의 **종류**(개념용인지
절차용인지)를 바꿀 수 있다 — 어느 과목보다 중요한 후속 질문이다.

### 문서 내용 — 통합 수업안 (`id: teacher_plan`) — 최대 5쪽

원본 수업의 단계 구조를 재현한다(예: 문제 만나기 → 스스로 해결하기 → 풀이 나누기 → 정리하기 →
정리 문항). 원본에 없는 단계를 지어내지 않는다. 각 `##` 제목이 한 절이 된다.

```markdown
# 차별화 수업안: [수업 제목]

**성취기준:** [원문 그대로]  **학년:** [X]  **차시:** [X분]
**앵커 문제:** [한 문장]
*학생 정보: [없으면 "보편적 설계 기본값 적용 — 세 수준 모두 문장 지원과 어휘 지원."]*

## 학습 목표
[세 수준을 아우르는 한 진술. 3범주가 다 보이게.]

## 3범주 지도
- **지식·이해:** [10어절 이내]
- **과정·기능:** [이 차시의 동사]
- **가치·태도:** [관찰 가능한 행동으로]
```

### 문서 내용 — 학습지 (`id: worksheet_group_a` / `worksheet_group_b` / `worksheet_group_c`)

학습지에는 교사 노트·관찰 지점·설계 근거가 없다. 어휘, 문장 지원, "먼저 끝냈다면", 성찰 발문은
`shared`에서 끌어오므로 세 수준에서 구조적으로 같다. 인쇄된 지면에 "CRA", "스캐폴드" 같은 교사 말을 쓰지
않는다.

| 수준 | 학습지 특징 |
|---|---|
| 기초(가) | 보통과 같은 문제. R3 진입점(구체물·그림)과 R4 스캐폴드를 R7 제거 방식으로 삽입. |
| 보통(나) | 원본 학습지를 유지하거나 가볍게 재구성. |
| 심화(다) | 같은 문제 + R7 확장 문제 1개(자체 제목 절). |

```markdown
# [가 모둠 / 나 모둠 / 다 모둠] — [수업 제목]

## 어휘
[`from_shared: vocabulary`]

**다음 문장 지원을 쓸 수 있습니다:**
- "나는 ____과 ____을 알아요. 모르는 것은 ____이에요."
- "____이 ____보다 커요. 왜냐하면 ____."

[문제는 하나씩: 기초 수준만 스캐폴드 블록 최대 하나("문제 N을 하기 전에 —"), 그다음
`{"type": "from_shared", "key": "pN", "label": "N"}`과 풀이 공간. 문제 글은 세 수준에서 같으며 다시
타이핑하지 않는다.]

## 먼저 끝냈다면
[`from_shared: anchor_activity`]

## 되돌아보기
[`from_shared: reflect_prompt`]
```

## differentiation.json 작성 — 수학 매핑

- `shared.subject`: `"수학"` (렌더러가 풀이 공간을 줄 없이 잡는다)
- `shared.grade`: 영문 학년을 앞에 (`"Grade 4 · 초등학교 4학년"`)
- `shared.standard_code` / `shared.standard_text`: 코드와 원문 — 초등 수학 절취 결함 처리는 수업 설계
  레퍼런스의 매핑과 같다(문장 끝 "다." 뒤 꼬리만 자르고 밝힌다)
- `shared.anchor_task`: 앵커 문제
- `shared.p1`..`pN`: 세 수준이 공유하는 문제, 키 하나에 문제 하나 — `{teacher: "맡은 구조 사례와 볼 것",
  student: <문제>}`
- `shared.sentence_frames`, `shared.anchor_activity`, `shared.reflect_prompt`, `shared.vocabulary`
- 교사 문서: 통합 차별화 수업안, 최대 5쪽. 학습지는 각 최대 2쪽
- **저작권:** 검정 교과서·익힘책·시중 문제집의 문제와 삽화를 옮기지 않는다 — 수와 맥락을 새로 만든다
