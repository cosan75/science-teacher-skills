# 통합교과 — 차별화 pedagogy (초1–2)

`ko12-lesson-differentiation`에서 과목이 **통합교과**(바른 생활·슬기로운 생활·즐거운 생활, 초1–2)일 때 로드된다
(SKILL.md 과목 레지스트리). `[2건…]` 건강한 생활(2028년 3월 적용 예정)은 범위 밖이다.

**1–2학년 차별화의 중심은 읽기 양이 아니라 참여 방식이다.** 모든 수준이 같은 놀이를 같은 시간에 한다.
달라지는 것은 기초 수준이 **함께**(교사·짝과 같이) 하고, 보통 수준이 **스스로** 하며, 심화 수준이 **새로
만든다**(규칙을 바꾸거나, 까닭을 말하거나, 다른 대상에 옮긴다)는 점이다.

## 원본 수업 확인

**시나리오 A — 이 대화 앞부분에 원본 수업이 있다.** 그대로 쓴다.
**시나리오 B / B2 — 파일이나 링크로 받는다.** 먼저 읽고 학년, 성취기준(묶은 것 모두), 중심 놀이, 수업 단계를
확인한다. 읽히지 않으면 분명히 말하고 다시 요청한다. 조용히 지어내지 않는다.
**가져온 것으로 Step 1이 끝날 뿐, 성취기준 확인을 대신하지 않는다.** Step 2로 계속한다.
**시나리오 C — 원본 수업이 없다.** 묻는다: *"차별화 도와드릴게요. 염두에 둔 수업이 있으신가요? 붙여넣거나
파일로 주셔도 되고, 학년 + 주제 + 성취기준만 알려 주셔도 그걸로 만들 수 있어요."*

## 차별화 규칙

### R1 — 산출 구조

**교사용 통합 차별화 수업안 1종 + 학생용 활동지 3종(가·나·다 모둠).** 수준별 수업안 3종을 만들지 않는다. 모두가
함께하는 단계(놀이 열기, 놀이 나누기)는 한 번만 쓰고, 놀이하기와 생활로 잇기의 수준 차이는 한 표에 나란히 보인다.

### R2 — 3범주 범위 보존

**모든 수준이 묶은 성취기준 모두를 다룬다.** 기초 수준이라고 슬기로운 생활의 탐구를 빼고 색칠만 시키거나, 바른
생활의 실천을 빼지 않는다. 세 범주(지식·이해 / 과정·기능 / 가치·태도)가 세 수준 모두에 있다.

### R3 — 함께 → 스스로 → 새로 만들기로 끌어올리기

| 수준 | 진입점 |
|---|---|
| 기초(가 모둠) | **함께**: 교사나 짝이 먼저 해 보이고 따라 한다. 고를 수 있는 그림 보기를 준다 |
| 보통(나 모둠) | **스스로**: 놀이 규칙대로 혼자·모둠이 해낸다 |
| 심화(다 모둠) | **새로 만들기**: 까닭을 말하거나, 규칙을 하나 바꾸거나, 다른 대상에 옮긴다 |

기초 수준의 도움은 선수 경험(유치원·1학년 1학기의 비슷한 놀이, 가정의 경험)에 닻을 내린다 — "집 앞에서 본
가게를 떠올려 볼까?" 같은 발문으로 학생의 실제 경험에서 출발한다.

### R4 — 기초 수준 스캐폴드

쓰는 것: ✓ 그림 보기(3개 이하) + "다른 것 그리기" 칸 ✓ 교사·짝의 시범 ✓ 말로 답하고 교사가 받아 적기 ✓ 손가락
짚기, 몸짓 흉내.
하지 않는 것: ❌ 답을 그려 둔 칸에 색칠만 하기 ❌ 놀이에서 빼내 따로 학습지 풀기 ❌ 글을 읽어야 하는 도움말.

#### 스캐폴드 밀도 상한

활동 하나에 삽입 도움 1–2개까지. 활동지 위의 그림 낱말 상자와 교사의 시범은 세지 않는다.

### R5 — 필수 교수학습 장치

| 요소 | 무엇인가 | 어디에 |
|---|---|---|
| **형성 확인** | 놀이 중 관찰 확인 + 정리 문항(그림·말) — 계기와 볼 것을 이름 붙인다 | 수업안 |
| **앵커 활동** | 먼저 끝낸 학생의 놀이 확장 과제. `shared.anchor_activity`에 학생 대면으로 쓰고 활동지 3종에 인쇄 | 수업안 + 활동지 3종 |
| **유연한 편성 문구** | 수준은 오늘 놀이의 관찰로 정하며 바뀔 수 있다는 진술 | 수업안 머리 |
| **수준별 예상되는 학생 생각** | 흔한 생각 + 교사 발문, 수준당 2문장 이내 | 수준별 활동 표 아래 콜아웃 |

**각 활동지는 세 수준 공통의 되돌아보기로 끝난다** — 기분 고르기(세 칸에 ○표: 신났어요 / 괜찮았어요 /
어려웠어요)와 "오늘 가장 재미있었던 것 그리기". `shared.reflect_prompt`에 저장한다.

### R6 — 보이지 않는 조정

**같은 놀이, 같은 공간, 같은 결과물. 도움만 다르다.** 모둠을 수준별로 나눴다는 것을 학생에게 말하지 않는다 —
모둠 이름은 가·나·다일 뿐이다. 놀이 나누기는 세 모둠이 섞여서 한다.

### R7 — 수준 내 점진적 스캐폴딩

기초 수준 활동지는 첫 활동에 그림 보기를 주고, 두 번째 활동에서는 보기 없이 그림 칸만 둔다(알리지 않는다).
심화 확장은 **보통 수준이 하지 않는 새 생각**이어야 한다 — 까닭 말하기, 규칙 바꾸기, 다른 장소·대상에
옮기기, 친구에게 가르쳐 주기. 거절할 것: 같은 그림을 더 많이 그리기, 색칠 더 하기.

### R8 — 범위와 기본값

수준 범위가 없으면 묻는다: *"가·나·다 세 모둠으로 나눌게요 — 괜찮을까요? 한글 해득이 아직인 학생이나 특별히
알아 둘 학생이 있으면 알려 주세요. 없으면 세 모둠 모두 그림 보기와 말로 답하기를 기본으로 넣을게요."*
기본값: 가 / 나 / 다 모둠, 세 모둠 모두 그림 낱말 상자, 수업 전체. 생성 뒤에 묻는다: *"지난 시간 관찰 기록이
있으신가요 — 놀이에 잘 끼지 못한 학생이나 말로는 잘하는데 그리기를 어려워한 학생 같은 것이요."*

### 문서 내용 — 통합 수업안 (`id: teacher_plan`) — 최대 4쪽

science.md(차별화)의 통합 수업안 개요를 그대로 쓰되 용어를 바꾼다: 앵커 현상 → **중심 놀이**, 탐구 활동 →
**놀이하기**. 절: 한눈에 보기(주 성취기준 콜아웃 + 묶은 성취기준 코드·요지) / 3범주 지도 / 수준 편성 /
[전체 활동] / [수준별 활동 — 표: 진입점 · 학생이 하는 일 · 활동지 과제] / 형성 확인 / 앵커 활동 / 이 설계가 통하는
이유 (1)·(2) / 다음 단계. **"이 설계가 통하는 이유 (1)·(2)"는 필수다.**

### 문서 내용 — 활동지 (`id: worksheet_group_a` / `worksheet_group_b` / `worksheet_group_c`)

활동지에는 교사 노트가 없다. 글은 교사가 읽어 줄 짧은 지시뿐이고, 답은 그림 칸(`ruled: false`)과 ○표로 받는다.
각 활동지 1–2쪽. 구성: 그림 낱말 상자 → 놀이 과제(`from_shared: play`) → 생활로 잇기 → (다 모둠만) 더 해 보기 →
오늘 알게 된 것 → 먼저 끝냈다면 → 되돌아보기.

## differentiation.json 작성 — 통합교과 매핑

- `shared.subject`: `"통합교과"`, `shared.grade`: `"Grade 1 · 초등학교 1학년"` 형식
- `shared.standard_code` / `shared.standard_text`: 주 성취기준 — 학습맵 요약 문장이므로 수업안 끝에 대조 안내를
  단다(수업 설계 레퍼런스 매핑과 같음)
- `shared.play`, `shared.play_rules`, `shared.life_link`, `shared.exit_ticket`, `shared.anchor_activity`,
  `shared.reflect_prompt`, `shared.picture_words`(그림 낱말 상자 — `table`)
- 기초 수준의 그림 보기는 기초 활동지의 해당 활동 바로 위에만 둔다(`shared.scaffold_a_*`)
- **저작권:** 현행 동요·그림책의 가사·본문, 교과서 삽화를 싣지 않는다
