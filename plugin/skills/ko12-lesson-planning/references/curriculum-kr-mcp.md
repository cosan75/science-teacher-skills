# 한국 교육과정 학습맵 MCP — 호출 시퀀스

`ko12-lesson-planning` Step 2에서 **학습맵 MCP 도구가 연결된 경우에만** 사용한다.
연결되지 않았다면 이 파일 전체를 건너뛴다 (SKILL.md Step 2에 폴백 있음).
연결됐는데 호출하지 않는 것은 치명적 실패(critical failure)다.

## 서버 라우팅 (모든 과목 공통)

두 개의 독립 MCP 서버가 있다. **서로 다른 그래프이며 교차 조회되지 않는다.**

| 학교급 | 서버 | 도구 접두 신호 |
| --- | --- | --- |
| 초등 (1–6학년) | `curriculum-kr-elementary` | 성취기준 코드 `[2xx…]` `[4xx…]` `[6xx…]` — `gradeBand: "1-2" \| "3-4" \| "5-6"` |
| 중·고 (보통교과) | `curriculum-kr-secondary` | 코드 `[9xx…]` (중), `[10xx…]` `[12xx…]` (고) — `schoolLevel: "middle" \| "high"`, `gradeBand: "7-9" \| "10" \| "10-12"` |

**두 서버의 차이 (실측):**
- 초등에는 `get_transitions`가 없다 (중→고 전이는 중등 전용). 초등은 9종, 중등은 11종.
- 초등 `search_standards` 결과의 요약 필드는 `summary`가 아니라 **`focus`**이며 문장이 잘려 있다.
  초등 `get_standard`에는 `subject` 파라미터가 없다.
- ⚠ **초등 성취기준 원문은 verbatim이 아니다.** 초등 레코드는 `sourceTextIncluded: false`이고
  `sourceBasis`에 "표준 본문은 저작권 정책상 재수록하지 않는다"고 명시돼 있다. `officialText`
  필드는 존재하지만 `focus + "할 수 있다"`로 조립된 값이다. 따라서 **초등 수업안에서는 성취기준을
  verbatim으로 인용했다고 말하지 않는다** — 콜아웃에 이 문장을 쓰되 수업안 푸터에 다음을 단다:
  *"초등 성취기준 문장은 학습맵의 요약 필드에서 재구성된 것입니다. 공식 고시문과 대조해 확인하세요."*
  중등은 `sourceLocator`(PDF 쪽·sha256)를 갖춘 verbatim이므로 이 제한이 없다.

라우팅 규칙:
- 교사가 말한 **학년**으로 서버를 정한다. 중학교 수업이면 secondary만 호출한다.
- 단, **선수학습 결손 진단** 맥락(중1 대상, "기초가 안 된", "초등 내용부터")이 명시되면
  elementary를 추가 호출해 초등 성취기준을 역추적한다.
- **초→중 브리지는 두 그래프 어디에도 없다.** 초등 결손 추적은 코드 연결이 아니라
  **키워드 병렬 검색**으로 한다: 같은 주제어로 두 서버의 `search_standards`를 각각 호출하고,
  학년군 순서로 모델이 직접 잇는다. 이 연결은 "추정 연계"임을 산출물에 표시한다.
- 중→고 심화 연계는 secondary의 `get_transitions`가 공식 근거(별책) 기반으로 제공한다 — 추정 아님.

## 성취기준 확정 (모든 과목 공통)

원본의 `find_standard_statement` 역할을 3개 도구가 분담한다:

- **코드가 주어진 경우** ("[9과01-01]", "9과01-01" 둘 다 수용): `get_standard(code, subject?)` 직행.
  코드 공유 과목(12스문·12심독 계열 11개)은 `subject` 파라미터로 구분해야 한다.
  코드 형식이 안 맞아 실패하면 → 키워드 검색으로 폴백; 반환된 실제 `code` 값으로 형식을 확인해 재시도.
- **코드가 없는 경우**: `search_standards(query, schoolLevel?, subject?, domain?, gradeBand?)` —
  요약 목록 반환. `gradeBand`는 `"7-9"`(중) / `"10"`(고 공통) / `"10-12"`(고 선택).
  성취기준 **원문 표현**으로 찾아야 할 때는 `search_standard_text(query, …)`(전문 검색, 매칭 스니펫)를 쓴다.
  가장 적합한 항목을 고르고 `get_standard`로 전체 레코드 + **공식 원문** + 연결 주제를 가져온다.
- **총 검색 시도 3회 상한.** 엉뚱한 학년군·과목 결과는 실패로 계산 — 남은 시도는 다른
  키워드(과목명, 영역명, 소재)로 쓴다. 3회 후에도 없으면 검색 중단, 훈련 지식의 최적
  성취기준으로 진행하고 부분-커버리지 푸터를 수업안에 단다.

확정된 성취기준에서 추출: **`officialText`**(공식 원문 — 수업안 성취기준 콜아웃에 verbatim 인용),
`code`, 그리고 연결된 **주제 ID 목록**(`linkedTopics[].id` — 이후 호출에 필요, 저장).
⚠ `summary` 필드는 기계 생성 요약(`summaryKind: "mechanical-derivative"`)이다 — 인용에 쓰지
않는다. 원문은 `officialText`뿐이다.

## 과목 공통 호출 시퀀스 — 전용 절이 없는 과목

아래 *과학* 절의 1–6단계는 과목에 묶인 것이 아니라 학습맵 도구의 데이터 흐름(성취기준 →
주제 ID → 선수관계·세부 주제·전이)을 따른 것이다. **자기 절이 없는 과목은 과학 절의 1–6단계를
그대로 따른다** — 단, `search_standards`의 `subject` 파라미터를 그 과목명으로 바꾸고, 5단계
오개념은 과목 레퍼런스가 정한 "예상되는 학생 생각" 형식으로 쓴다. 과목 고유의 호출이 필요해지면
(예: 국어의 제재·갈래 검색, 수학의 선수 위계 심층 조회) 이 파일에 `## <과목>` 절을 새로 쓰고
과목 레퍼런스의 *성취기준 근거 확보* 절에서 그 절을 가리킨다.

## 통합교과 (바른·슬기로운·즐거운 생활) — 초1–2

> 이 포크에서 작성(2026-09-23). 초등 통합교과 레코드는 이 날 라이브 MCP로 실측했다.

초안 작성 **전에** 호출한다. 연결됐는데 호출하지 않으면 치명적 실패다. 서버는 `curriculum-kr-elementary`
(학년군 `"1-2"`). **묶은 성취기준(보통 2개) 각각**에 1단계를 하고, 2–3단계는 하나의 병렬 배치로 실행한다.

**초등 통합교과 레코드의 실측 특성:**
- 코드: `[2바QQ-NN]` 바른 생활 / `[2슬QQ-NN]` 슬기로운 생활 / `[2즐QQ-NN]` 즐거운 생활. `QQ`는 영역(삶의 질문) —
  01 누구로 / 02 어디서 / 03 지금 어떻게 / 04 무엇을 상상하며. `domainKorean`에는 교과명(예: "슬기로운 생활")이 온다.
- ⚠ **`officialText`는 원문이 아니라 요약이다.** 레코드가 `officialTextIncluded: false`이고 `sourceBasis`가
  "원문 대신 원문에서 끌어낸 간결한 풀어쓰기를 담는다"고 밝힌다. 콜아웃에 쓰되 verbatim이라고 말하지 않고,
  `integrated.md` 매핑의 대조 안내를 단다.
- ⚠ **`[2건…]` 건강한 생활**도 같은 과목 목록(`kr-2022-elem-integrated`)에 있으나 2028년 3월 적용 예정 교과이며,
  `officialText`가 표 절취로 깨져 있다. 조회하지 않는다(범위 밖 — `integrated.md` 확인 절 참조).
- 세부 주제는 교과마다 세 관점이다 — 바른: *생활 맥락 이해 / 바른 생활 실천 / 성찰과 습관화*, 슬기: *탐구 질문
  만들기 / 관찰과 자료 읽기 / 탐구 결과 설명*, 즐거운: *감각과 상상 열기 / 놀이와 표현하기 / 감상과 나눔*.

1. **성취기준**: `get_standard(code)` — 코드가 없으면 `search_standards(query, gradeBand: "1-2")`로 찾되 결과의
   `subjectKorean`이 "통합교과"이고 `domainKorean`이 바른·슬기로운·즐거운 생활인 것만 쓴다. 같은 영역(`QQ`)에서
   다른 교과 성취기준 하나를 짝으로 고른다.

2. **선수 학습**: `get_prerequisites(<주제>, depth: "all")`. edge는 `soft`("영역 안의 순차 학습 제안", "통합 흐름에서
   바른 생활 실천 경험이 슬기로운 생활 탐구 질문을 뒷받침")가 대부분이다 — 코드 + 요지로 쓰고 **"순차 제안"**
   표시를 단다. 공식 선수관계로 단정하지 않는다.

3. **세부 학습 주제**: 묶은 성취기준의 주제에 `get_topic` → `evidence[]`, `assessmentPrompt`. 세 관점을 수업
   단계에 옮긴다 — 슬기의 *탐구 질문 만들기*·즐거운의 *감각과 상상 열기*는 놀이 열기로, *관찰과 자료 읽기*·
   *놀이와 표현하기*는 놀이하기로, *탐구 결과 설명*·*감상과 나눔*은 놀이 나누기로, 바른의 *실천*·*성찰과
   습관화*는 생활로 잇기로. 템플릿형 서술이므로 시드로만 쓴다.

4. **심화 연계**: 호출하지 않는다(초등 서버에 `get_transitions` 없음).

5. **예상되는 학생 생각**: 학습맵에 없다. 훈련 지식에서 최대 3개 — 1–2학년의 흔한 생각(내 경험만을 전부로
   보기, 눈에 보이는 것만 보기, 규칙은 어른이 정하는 것). 형식: *학생의 생각* / *그렇게 생각하는 이유* /
   *교사의 대응*.

6. **커리큘럼 자료**: 검색하지 않는다. 교과서 활동·삽화, 현행 동요 가사를 재현하지 않는다.

**학습맵 미연결 시:** 최선의 지식으로 작성하고 푸터 추가:
*"한국 교육과정 학습맵 미연결 상태에서 생성됨. 성취기준 표현과 예상되는 학생 생각은 일반적 모범 사례 기준."*

→ **학습맵 단계 완료. 곧장 Step 3으로.**

## 수학 (Mathematics) — 초등

> 이 포크에서 작성(2026-09-23). 초등 수학 레코드는 이 날 라이브 MCP로 실측했다.

초안 작성 **전에** 호출한다. 연결됐는데 호출하지 않으면 치명적 실패다. 조회 결과를 채팅에 요약하지
않고 성취기준 한 줄 읽어주기로만 드러낸다. 서버는 `curriculum-kr-elementary`만 쓴다(학년군 `"1-2"`/
`"3-4"`/`"5-6"`). 성취기준을 확정한 뒤 2–3단계를 **하나의 병렬 배치**로 실행한다.

**초등 수학 레코드의 실측 특성:**
- `search_standards`의 `focus`는 "분수 소주제의 수와 연산 성취기준 [4수01-09]"처럼 **소주제 이름**을
  담는다 — 후보를 좁히는 데 쓰고 인용하지 않는다. 성취기준 원문 검색은 `search_standard_text`가 낫다.
- ⚠ **`officialText` 꼬리 결함.** 문장 끝 뒤에 다음 소주제 이름이 붙어 오는 항목이 있다(예:
  `[4수01-11]` → "…설명할 수 있다. 소수"). 문장을 끝내는 "다." **뒤의 꼬리만** 잘라 쓰고 설계 노트에
  밝힌다(`math.md` 매핑). 문장 안은 고치지 않는다.
- 세부 주제는 성취기준마다 **개념 확인 / 표현과 연결 / 적용과 설명** 세 관점이다
  (`…s4-01-11.concept` / `.representation` / `.application`).

1. **성취기준**: 위 *성취기준 확정* 절차대로(`get_standard`는 코드만으로). 연결 주제 ID를 저장한다.

2. **선수 학습**: `get_prerequisites(<.concept 주제>, depth: "all")` → 경로(`pathOrder[]`)의 끝부분.
   ⚠ **성취기준 사이의 edge는 `soft`("공식 코드 순서에 따른 후보 선행 관계")다** — 코드 번호 순서일 뿐
   내용상 선수 근거가 아니다. `hard` edge는 한 성취기준 안의 개념 → 표현 → 적용 순서다. 경로의 마지막
   2–3개 성취기준 가운데 **이 개념에 실제로 필요한 것**을 골라 코드 + 10어절 이내 요지로 쓰고
   **"학습맵 코드 순서 후보"**라고 표시한다(예: `[4수01-11]` 분수 크기 비교 ← `[4수01-09]` 등분할로 분수
   이해하기 — 바로 앞 코드 `[4수01-10]`(분수의 종류)보다 이 차시에 필요한 개념이다). 공식 선수관계로
   단정하지 않는다. 경로가 비었으면 이전 학년군의 같은 영역에서 찾아 "추정"을 표시한다.

3. **세부 학습 주제**: 세 관점 주제에 `get_topic` → `evidence[]`, `assessmentPrompt`(단수). 템플릿형
   서술이므로 **시드로만** — *개념 확인*은 예와 예가 아닌 경우(정리 문항의 판별 사례 후보), *표현과
   연결*은 두 가지 이상의 표현 잇기(풀이 나누기의 구체물 → 그림 → 식 순서), *적용과 설명*은 풀이 과정과
   타당성 설명(정리하기의 연습 문제와 초5–6 설명 쓰기)으로 옮긴다.

4. **심화 연계**: 호출하지 않는다(초등 서버에 `get_transitions` 없음). "이후 ___로 심화된다"를 지어내지
   않는다.

5. **예상되는 학생 반응**: 학습맵에 없다. 훈련 지식에서 2–3개, 각각 **틀린 식이나 틀린 답의 형태**로
   (예: "1/3 < 1/5이라고 쓴다", "403−158=355"). 형식: *학생의 반응* / *그렇게 되는 이유* / *교사의 대응*.

6. **커리큘럼 자료**: 검색하지 않는다. 교과서·익힘책 문제를 재현하지 않고 수와 맥락을 새로 만든다.

**학습맵 미연결 시:** 최선의 지식으로 작성하고 푸터 추가:
*"한국 교육과정 학습맵 미연결 상태에서 생성됨. 성취기준 표현과 예상되는 학생 반응은 일반적 모범 사례 기준."*

→ **학습맵 단계 완료. 곧장 Step 3으로.**

초안 작성 **전에** 호출한다. 연결됐는데 호출하지 않으면 치명적 실패다. 조회 결과를 채팅에 요약하지
않고, 초안의 성취기준 한 줄 읽어주기로만 드러낸다. 서버는 `curriculum-kr-elementary`만 쓴다(학년군
`"1-2"`/`"3-4"`/`"5-6"`). 성취기준을 확정한 뒤 2–3단계를 **하나의 병렬 배치**로 실행한다.

**초등 국어 레코드의 실측 특성** (원 저장소 2026-09-01 실사):
- 코드 `[2국QQ-NN]`·`[4국QQ-NN]`·`[6국QQ-NN]`의 `QQ`가 영역이다 — **01 듣기·말하기 / 02 읽기 /
  03 쓰기 / 04 문법 / 05 문학 / 06 매체.** 영역 파일(`korean-domains/`) 선택에 쓴다.
- ✅ **초등 국어 `officialText`는 고시문 원문이다** — 초등 국어 87건 실사에서 추출 오류 0건.
  `sourceTextIncluded: false` 플래그는 낡은 메타데이터이므로 무시하고 필드를 본다. 그대로
  `shared.standard_text`에 넣고, 위 *서버 라우팅* 절의 과학용 "재구성된 문장" 푸터는 국어에는 달지
  않는다. `officialText`가 `null`이면 그때만 `korean.md`의 미확인 표기 규칙을 따른다.
- ⚠ **domain 필터 함정.** 영역명 구분자는 가운뎃점 `·`(U+00B7)이 아니라 `⋅`(U+22C5)다 —
  `domain: "듣기·말하기"`로 필터하면 0건. **`domain` 파라미터는 쓰지 않는다**(영역은 코드로 안다).

1. **성취기준**: 위 *성취기준 확정* 절차대로(`get_standard`는 코드만으로). 연결 주제 ID와
   `domainKorean`을 저장한다.

2. **선수 학습**: `get_prerequisites(topicId, depth: "all")`. 초등 국어는 edge가 있지만
   `strength: "soft"`, 사유가 "학년군 안의 순차 학습 **제안**"인 경우가 많다 — `soft`면
   **"순차 제안"**으로 표시하고 공식 선수관계로 단정하지 않는다. edge가 없으면 **이전 학년군의 같은
   영역**(같은 `QQ`) 성취기준을 `search_standards(query, gradeBand: <이전 학년군>)`로 찾아 코드 + 10어절
   이내 요지로 쓰고 **"계열 추정"**을 표시한다.

3. **세부 학습 주제**: `get_topic(topicId)` — 초등은 평가 문항이 `assessmentPrompt`(**단수**),
   `evidence[]`는 2개. 관점은 영역마다 다르다(예: 문학 5–6 — 작품 요소와 갈래 단서 파악 / 감상 근거와
   반응 표현 / 상상·창작·낭송 수행 / 문학 향유와 삶 연결 성찰). 템플릿형이므로 **시드로만** 쓴다 —
   관점을 목표·관찰 포인트의 뼈대로, `evidence`를 이번 제재와 활동의 구체적 학생 행동으로 재진술.

4. **심화 연계**: 호출하지 않는다(초등 서버에 `get_transitions` 없음). "이후 ___로 심화된다"를
   지어내지 않는다.

5. **예상되는 학생 반응과 어려움**: 학습맵에 없다. 훈련 지식에서 최대 3개. **영역마다 성질이
   다르다** — 문법은 잘못 아는 규칙, 읽기는 흔한 오독(근거 건너뛴 추론), 쓰기는 흔한 약점(독자·목적
   미고려), 듣기·말하기는 흔한 회피(원고 읽기), 문학은 **오개념 틀을 쓰지 않고** 근거 없는 감상·줄거리
   요약으로 대체하기, 매체는 무비판적 수용. 형식: *학생의 반응* / *그렇게 되는 이유* / *교사의 대응*.

6. **커리큘럼 자료**: 검색하지 않는다. 성취기준·주제 데이터와 `korean-text-sourcing.md`로 조달한
   제재만으로 설계한다.

**학습맵 미연결 시:** 최선의 지식으로 작성하고 푸터 추가 —
*"한국 교육과정 학습맵 미연결 상태에서 생성됨. 성취기준 표현은 일반적 모범 사례 기준."* — 그리고
`shared.standard_text` 끝에 `(원문 미확인 — 학습맵 미연결 상태에서 작성)`을 붙인다(`korean.md` 매핑).

## 사회 (Social Studies) — 초등

> 출처: newskool4d-sketch/social-teacher-skills(Apache-2.0)의 사회 절에서 **초등 부분만** 이식.
> 중·고 사회·통합사회·역사 라우팅은 옮기지 않았다(레지스트리 planned).

초안 작성 **전에** 호출한다. 연결됐는데 호출하지 않으면 치명적 실패다. 모든 호출을 마치고
아래 명시된 것만 추출한 뒤 곧장 Step 3으로 간다 — 학습맵 조회 결과는 채팅에 요약하지 않고,
초안의 성취기준 한 줄 읽어주기(read-back)로만 드러낸다. 서버는 `curriculum-kr-elementary`만
쓴다. 성취기준을 확정한 뒤 2–3단계 호출을 **하나의 병렬 배치**로 실행한다.

**초등 사회 레코드의 실측 특성** (원 저장소 2026-08-29 실측, 이 포크에서 2026-09-23 라이브 재확인):
- `search_standards` 결과의 `focus`가 **사회 레코드는 빈 값**이다 — 요약 필드에 기대지 말고
  코드·영역명(`domainKorean`)이나 `get_standard`의 `officialText`로 확인한다.
- ⚠ **`officialText`는 조건부 verbatim이다.** NCIC 고시 PDF에서 자동 추출한 원문이며(재구성 값이

  해설 문단이 성취기준 자리에 섞이거나(예: `[4사09-01]`이 "~능력을 기른다"로 끝나는 해설 문장으로
  반환됨) 문장이 다음 제목까지 잘린다. 원문은 **반환된 그대로** 인용하되(고쳐 쓰지 않는다), 결함이
  보이는 항목은 수업안 푸터에 다음을 단다:
  *"초등 성취기준 원문은 NCIC 고시 PDF에서 자동 추출한 것입니다(재구성 아님). 다만 일부 항목(약 8%)은
  절취 과정에서 해설 문단이 섞이거나 문장이 잘렸을 수 있으니, 인용 전 공식 고시문과 대조해 확인하세요."*

1. **성취기준**: 위 *성취기준 확정* 절차대로. `get_standard`는 코드만으로 호출한다(초등에는

2. **선수관계**: `get_prerequisites(topicId, depth: "all")` → 위상 정렬된 선수 경로에서 **직전 선수

3. **세부 학습 주제**: 저장한 주제 ID들에 `get_topic(topicId)` → 관찰 증거(`evidence[]`)와

4. **심화 연계**: **호출하지 않는다.** 초등 서버에는 `get_transitions`가 없다. "이후 ___로

5. **예상되는 학생 생각**: 학습맵에 이 데이터가 없다. 훈련 지식에서 최대 3개, 성취기준 원문과

## 과학 (Science)

초안 작성 **전에** 호출한다. 연결됐는데 호출하지 않으면 치명적 실패다. 모든 호출을 마치고
아래 명시된 것만 추출한 뒤 곧장 Step 3으로 간다 — 학습맵 조회 결과는 채팅에 요약하지 않고,
초안의 성취기준 한 줄 읽어주기(read-back)로만 드러낸다.

호출 간 데이터 의존은 성취기준의 **주제 ID**(2–4단계에서 사용) 하나뿐이다. 따라서:
성취기준을 확정한 뒤, 2–4단계 호출을 **하나의 병렬 배치**로 실행한다.

**사용 도구:** `search_standards`, `search_standard_text`, `get_standard`, `search_topics`,
`get_topic`, `get_prerequisites`, `get_learning_roadmap`, `get_transitions`(secondary 전용),
`list_clusters`.

1. **성취기준**: 위 *성취기준 확정* 절차대로. `get_standard`가 반환한 **공식 원문**을
   수업안의 성취기준 콜아웃에 그대로 쓴다. 연결 주제 ID들을 저장한다.

2. **선수관계**: `get_prerequisites(topicId, depth: "all")` → 추출: 위상 정렬된 선수 경로
   (`pathOrder[]`)에서 **직전 선수 주제 1개**(그 주제가 속한 성취기준 코드 포함). 학습 목표
   섹션에 사용. 학습맵에 edge가 있는데 명시하지 않는 것은 치명적 실패다.
   ⚠ **edge가 없는 성취기준이 많다** (중고 선수관계는 공식 근거가 있는 것만 보수적으로 수록,
   `directEdges: []`로 반환). 그 경우 훈련 지식으로 직전 선수 내용을 쓰되 **"추정"임을 수업안에
   표시한다** — 학습맵 근거인 것처럼 쓰지 않는다.
   중학교 수업 + 결손 진단 맥락이면 elementary 서버에도 키워드 병렬 검색(위 라우팅 규칙).

3. **세부 학습 주제**: 저장한 주제 ID들에 `get_topic(topicId)` → 추출: 관찰 증거(`evidence[]`)와
   평가 문항(`assessmentPrompts[]`), 관점 키(`facetKey` — 예: 탐구 설계와 자료 해석 /
   증거 기반 설명과 적용). 주제는 성취기준을 관점별로 분해한 **자동 생성 후보 단위**라 서술이
   템플릿형이다 — 그대로 복사하지 말고 **시드로 쓴다**: `facetKey` 관점을 수업 목표 불릿과
   look-for 행의 뼈대로 삼고, `evidence`를 이번 수업의 활동·소재로 구체화한 "구체적 학생 행동"으로
   재진술한다. `assessmentPrompts`는 형성평가·정리 문항(exit ticket) 설계의 시드. 나머지는 버린다.

4. **심화 연계** (secondary·해당 시): `get_transitions(standardCode 또는 topicId)` → 추출:
   이 내용이 고교 어느 과목·성취기준으로 이어지는지 1–2개(`asFrom`/`asTo`). 수업안 "단원 맥락"
   섹션에서 "이 내용은 이후 ___로 심화된다" 한 문장으로만 사용. 고교 수업이면 역방향(중학교
   기반)으로 조회. ⚠ 전이는 공식 근거가 있는 175건만 수록 — 빈 배열이 정상인 성취기준이 많다.
   없으면 이 문장을 생략한다 (훈련 지식으로 지어내지 않는다).

5. **오개념**: **학습맵에 오개념 도구가 없다.** 훈련 지식에서 3개를 작성하되, 각 항목은
   반드시 해당 성취기준의 원문 표현과 3단계에서 얻은 세부 주제에 정합해야 한다.
   형식: *학생의 생각* / *지속되는 이유* / *교사의 대응*.
   (오개념 데이터 소스가 별도 MCP로 연결된 경우 — 도구명에 misconception이 포함 —
   그쪽을 우선 호출하고 훈련 지식은 폴백으로 강등한다.)

6. **커리큘럼 자료**: **한국판에는 IM/OpenSciEd 대응 자료 검색이 없다.** 이 단계는 생략한다.
   교과서 출판사별 전개는 학교마다 다르므로, 수업안은 성취기준·주제 데이터만으로 독립적으로
   설계하고 특정 출판사 교과서의 활동·삽화·지문을 재현하지 않는다.

**학습맵 미연결 시:** 최선의 지식으로 작성하고 푸터 추가:
*"한국 교육과정 학습맵 미연결 상태에서 생성됨. 성취기준 표현과 오개념은 일반적 모범 사례 기준."*

→ **학습맵 단계 완료. 곧장 Step 3으로.**
